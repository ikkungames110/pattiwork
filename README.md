# Pattiwork

ボードゲーム「パッチワーク」(Uwe Rosenberg) をブラウザで遊べるようにしたものです。PeerJS (WebRTC) による P2P オンライン対戦と、1台でのローカル対戦に対応しています。

## 遊び方

```
npm install
npm run dev
```

- **オンライン対戦**: 片方が「ルームを作成」→ 表示されたコード / リンクを相手に送る → 相手がコードを入力して「参加」。
- **ローカル対戦**: 1台で交代しながらプレイ。
- 操作: パッチの輪から 1〜3 番目を選択 (キー 1/2/3) → キルト上をクリックで配置。R / 右クリックで回転、F で反転、Esc で取消。スマホは同じマスを 2 回タップで配置。

## 実装メモ

- 33 枚のパッチ、タイムトラック (54 マス, ボタン収入 9 か所, 1×1 パッチ 5 枚)、7×7 ボーナス、同点時は先にゴールした方の勝ち、など公式ルールを再現。
- ホストが状態を持つ権威サーバ方式。ゲストの操作はホストが検証して全状態を配信します。
- テスト: `npm test` (ランダムプレイで最後まで進むことを確認)
